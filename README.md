# Victor Vang — IT Home Lab

Hands-on IT labs built to develop real world help desk
and systems administration skills. Each lab simulates
tasks and scenarios commonly encountered in IT support
and systems administration roles.

## Labs

| Lab | Skills Demonstrated |
|---|---|
| [Active Directory](active-directory/README.md) | AD DS setup, user and group management, delegation, Group Policy |
| [Networking Fundamentals](networking/README.md) | VirtualBox network modes, TCP/IP, DNS, DHCP, connectivity troubleshooting |
| [osTicket](osticket/README.md) | Help desk ticketing workflow, SLA management, triage, ticket lifecycle |

## Environment

- Hypervisor: VirtualBox
- Windows Server 2022 (Domain Controller)
- Windows 11 (Client VM)
- Ubuntu Server 22.04 (osTicket host)

## Skills Covered

- Active Directory administration and Group Policy
- Network troubleshooting using ipconfig, ping, tracert, nslookup
- Help desk ticketing workflow and SLA management
- User account management and delegation of permissions
- Virtual machine configuration and network mode management
- Documentation and technical writing

## Tools Used

- VirtualBox
- Windows Server 2022
- Windows 11
- Ubuntu Server 22.04
- osTicket v1.18.4
- Apache, MariaDB, PHP
